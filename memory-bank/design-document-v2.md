## 1. 产品概述

### 1.1 产品定位
帮会管理系统是一款专为游戏帮会管理人员设计的一体化管理工具，涵盖成员管理、出勤考核、联赛排表、录屏审核和比赛数据分析等核心功能。

### 1.2 目标用户
- **开发者**（developer）：不绑定帮会，全局管理（创建帮会、派发账号、删除帮会）
- **管理员**（admin，帮会会长/副会长/官员）：进行帮会全面管理
- **帮众**（member）：查看出勤信息、提交录屏、查看数据分析

### 1.3 设计理念
- **大气简约**：宣纸鎏金主色调，营造高端大气的视觉氛围
- **优雅一致**：统一的色彩、字体、间距规范，柔和的圆角和阴影
- **高效易用**：常用功能易于触达，操作反馈及时明确

## 3. 用户角色与权限

### 3.1 账号模型
系统配置**三级角色**：
- **开发者账号**（developer）：不绑定帮会，可创建帮会、派发账号、删除帮会，拥有全局管理权限
- **管理员账号**（admin）：绑定帮会，拥有帮会内全部功能权限
- **帮众账号**（member）：绑定帮会，共享账号，拥有有限功能权限

每个帮会配置**两个账号**（管理员 + 帮众），由开发者创建。

### 3.2 权限矩阵
| 功能模块 | 开发者 | 管理员 | 帮众 |
|---------|--------|--------|------|
| 创建帮会 | ✅ | ❌ | ❌ |
| 删除帮会 | ✅ | ❌ | ❌ |
| 账号管理（创建/删除/启禁用） | ✅（全局） | ✅（本帮会） | ❌ |
| 职业配置 | ✅ | ✅ | ❌ |
| 常驻库管理（成员CRUD） | - | ✅ | ❌ |
| 出勤库管理（导入/编辑/保存） | - | ✅ | ❌ |
| 出勤表查看 | - | ✅ | ✅ |
| 单人请假操作 | - | ✅ | ✅ |
| 排表编辑（拖拽编排） | - | ✅ | ❌ |
| 排表总览查看 | - | ✅ | ✅ |
| 录屏链接提交 | - | ✅ | ✅ |
| 录屏审核 | - | ✅ | ❌ |
| 数据分析查看 | - | ✅ | ✅ |
| 数据分析导入CSV | - | ✅ | ❌ |
| 联赛日程管理 | - | ✅ | ❌ |

### 3.3 登录流程
- 开发者：账号密码登录，登录后进入系统配置（帮会管理 + 账号管理）
- 管理员：账号密码登录，登录后进入首页仪表盘，展示全部功能菜单
- 帮众：共享账号密码登录，登录后进入联赛总览，仅展示有限功能菜单
- 登录限流：连续 5 次失败锁定 5 分钟，锁定期间禁用输入框并显示倒计时

## 4. 功能模块设计

### 4.1 常驻库模块（成员管理）

#### 功能列表
| 功能 | 描述 |
|------|------|
| 添加成员 | 填写姓名、主职业、副职业（可选）、状态、备注 |
| 编辑成员 | 修改成员信息 |
| 删除成员 | 删除单个成员 |
| 批量删除 | 勾选多个成员批量删除 |
| 搜索 | 按姓名关键词搜索 |
| 职业筛选 | 按主职业/副职业筛选 |
| 状态筛选 | 按正式/替补筛选 |
| Excel导入 | 批量导入成员，自动识别职业列，重名跳过 |
| 出勤率统计 | 展示各成员出勤率，低于50%标红预警 |

#### 成员状态
- `formal`：正式成员
- `substitute`：替补成员

#### 职业列表（11种）
铁衣、血河、沧澜、龙吟、潮光、玄机、碎梦、神相、九灵、鸿音、素问

#### 出勤率计算公式
```
出勤率 = 请假次数 / (正常次数 + 请假次数) × 100%
```
- 仅统计该成员被导入出勤表的场次
- 未被导入出勤表的赛程不计入统计
- 中途加入帮会的成员，之前的赛程不算缺勤

### 4.2 出勤库模块

#### 场次管理
- 创建赛程时自动创建关联的出勤场次
- 删除赛程时联动删除关联的出勤数据

#### 出勤管理流程
```
进入赛程详情 → 切换到出勤库
    ↓
一键导入正式成员
    ↓
系统提示当前人数与60人上限的缺口
    ↓
选择填补方式：导入替补成员 / 添加补人（补人）
    ↓
设置出勤状态（正常/请假）→ 保存考勤
```

#### 出勤人数规则
- 出勤表正常状态人数上限为**60人**
- 可以不满60人保存出勤
- 缺口提示：导入后若未达60人，提示缺少人数

#### 补人规则
- 补人仅在当前场次的出勤表中存在
- 补人**不录入常驻库**
- 下次比赛自动消失，需重新添加

#### 帮众操作权限
- 帮众可查看出勤表
- 帮众可切换自己的出勤状态（正常/请假）

### 4.3 联赛排表模块

#### 页面结构
排表页面包含**三个核心模块**，排表总览在视觉布局和交互逻辑上需与候选池、具体排表明确区分：

```
┌─────────────────────────────────────────────────┐
│                  排表页面                         │
├─────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────────────────┐   │
│  │  候选池模块   │  │     具体排表模块         │   │
│  │             │  │                         │   │
│  │ 60人列表    │  │  10支队伍 × 6人/队      │   │
│  │ 可拖拽      │  │                         │   │
│  │             │  │                         │   │
│  └─────────────┘  └─────────────────────────┘   │
├─────────────────────────────────────────────────┤
│            排表总览模块（独立区域）                │
│  ┌─────────────────────────────────────────┐    │
│  │  成员列表 + 备注 + 位置信息              │    │
│  │  （供帮众查看自己在哪个位置）             │    │
│  └─────────────────────────────────────────┘    │
└─────────────────────────────────────────────────┘
```

#### 候选池
- 来源：出勤库中状态为**正常**的成员（含正式、替补、客人）
- 最多60人
- 支持拖拽到排表槽位

#### 排表结构（固定不可修改）

| 分类 | 队伍数量 | 每队人数 | 小计 |
|------|---------|---------|------|
| 进攻1 | 3队 | 6人 | 18人 |
| 进攻2 | 3队 | 6人 | 18人 |
| 防守1 | 2队 | 6人 | 12人 |
| 防守2 | 2队 | 6人 | 12人 |
| **合计** | **10队** | - | **60人** |

#### 排表交互
- 拖拽：从候选池拖拽成员到槽位
- 交换：两个槽位之间成员位置互换
- 角色标签：为槽位添加备注

#### 排表总览
- 展示内容：成员姓名、备注、所在位置
- 用途：发给帮众查看，让帮众知道自己在哪个位置
- 视觉设计：需与候选池和具体排表模块明显区分

#### 导出功能
- 导出排表为PNG图片

### 4.4 录屏审核模块

#### 使用场景
比赛后，帮众提交回放视频链接供管理员审查。

#### 数据来源
- 录屏列表展示**候选池中全部60人**（含正式、替补、补人）
- 根据赛程局数（1-3局），每人可提交对应数量的录屏URL

#### 功能列表
| 功能 | 描述 |
|------|------|
| 多局链接展示 | 同屏展示所有局数的链接输入框（不支持局数切换） |
| URL提交 | 帮众按局数提交录屏URL |
| URL校验 | 验证URL格式有效性（支持B站、YouTube等） |
| 审核通过 | 管理员审核通过，显示勾选标记 |
| 审核驳回 | 管理员驳回，要求重新提交 |
| 批量审核 | 批量审核通过多个帮众的录屏 |
| 审核筛选 | 按状态筛选（待审核/已通过/已驳回） |
| 全局进度 | 展示各局审核完成进度（如：第1局 45/60 已审核） |

#### 审核状态
- `pending`：待审核
- `approved`：已通过
- `rejected`：已驳回

#### 操作角色
- **帮众**：提交/修改自己的录屏链接
- **管理员**：审核通过/驳回，查看全局进度

### 4.5 数据分析模块

#### 数据导入
- 支持导入CSV格式的比赛数据（游戏内导出）
- CSV格式样例见 `.claude/docs/20260630_213158_横戈_仗剑.csv`
- 文件大小限制：5MB
- 数据与**赛程绑定**，按局导入（一局一表，重新导入覆盖该局数据）

#### 数据展示
| 展示项 | 描述 |
|--------|------|
| 多阵营对比 | 不同阵营的比赛数据对比（总览/阵营对比 Tab，含差值/波动值） |
| 击杀榜 | 各成员击杀数排行 |
| 伤害榜 | 各成员伤害输出排行 |
| 治疗榜 | 各成员治疗量排行 |
| 职业分析 | 按职业维度分析数据分布（职业分析 + 职业深度 17 项指标） |
| 衍生指标 | 16 项衍生指标（效率/生存/占比/技能四类），见数据列表 Tab |
| 小队分析 | 按排表小队维度分析我方成员（含小队对比与成员明细） |

#### 报告导出
- HTML 分析报告导出已移除（2026-08 数据分析模块重实施时删除，相关描述与代码同步清理）

#### 操作角色
- **管理员**：导入CSV、查看分析、调整小队分配
- **帮众**：查看分析数据

### 4.5.1 分析调整模块

#### 功能说明
小队分析 Tab 内，管理员可手动将"未排表成员"分配到指定队伍，用于分析视图中更精确的小队数据对比。该调整**仅作用于小队分析视图**，不改变正式排表数据。

#### 功能列表
| 功能 | 描述 |
|------|------|
| 读取调整 | 读取当前赛程的分析调整数据（帮众/管理员均可查看） |
| 保存调整 | 管理员保存「未排表成员 → 目标队伍」的分配方案 |
| 调整重置 | 覆盖式保存，新方案替换旧方案 |

#### 操作角色
- **管理员**：保存分析调整
- **帮众**：查看分析调整结果

### 4.6 联赛日程模块

#### 日程管理
| 功能 | 描述 |
|------|------|
| 创建赛程 | 填写对手、时间、地点，选择局数（1-3局） |
| 局数选择 | 1局/2局/3局，决定录屏链接数量，创建后不可修改 |
| 赛程日历 | 日历视图展示所有赛程 |
| 结果记录 | 记录胜负结果（win/lose/draw/pending） |
| 局数追踪 | 追踪每一局的比赛结果 |
| 级联删除 | 删除赛程时自动删除关联的出勤库、排表、录屏数据、分析数据 |

#### 赛程创建流程
```
创建赛程（对手/时间/地点）
    ↓
选择比赛局数（1局/2局/3局）
    ↓
系统自动创建（1:1:1:1关系）：
  - 出勤库（关联该赛程）
  - 排表（关联该赛程）
  - 录屏上传表（根据局数预留链接位置）
    ↓
进入赛程详情页统一管理
```

#### 数据关联关系
```
赛程 (1) ──→ (1) 出勤库
赛程 (1) ──→ (1) 排表
赛程 (1) ──→ (1) 录屏上传表
赛程 (1) ──→ (1) 数据分析
```

### 4.7 系统配置模块

#### 职业配置
- 配置各职业的目标人数（全局配置，所有比赛通用）
- 配置各职业的说明文字（remark，可编辑）
- 用于出勤库的职业缺口分析

#### 账号管理
| 功能 | 描述 | 权限 |
|------|------|------|
| 创建帮会 | 创建帮会，自动生成管理员账号和帮众账号 | 开发者 |
| 删除帮会 | 级联删除帮会全部关联数据（账号/成员/赛程/出勤/排表/录屏/分析/职业配置） | 开发者 |
| 创建账号 | 创建管理员或帮众账号，开发者可指定目标帮会 | 开发者/管理员 |
| 编辑账号 | 修改账号信息（重命名、重置密码） | 开发者/管理员 |
| 启用/禁用 | 启用或禁用帮会账号 | 开发者/管理员 |
| 删除账号 | 删除账号（不能删自己/开发者账号） | 开发者/管理员 |

#### 帮会管理（开发者专属）
| 功能 | 描述 |
|------|------|
| 帮会列表 | 查看所有帮会及其成员数 |
| 创建帮会 | 填写帮会名称，自动生成管理员和帮众账号 |
| 删除帮会 | 危险操作，二次确认后级联删除全部关联数据 |
