# UI风格参考文档

## 参考来源

**浅色雅金风（宣纸鎏金）**：以宣纸米白为底、鎏金为骨、墨色为文、朱砂为点睛，适用于逆水寒帮会联赛管理系统。

> 实现位置：`frontend/src/styles/`（theme.css 设计令牌 / element-plus.css 组件主题 / index.css 入口）

---

## 1. 设计原则

### 1.1 宣纸为底
- 页面背景采用宣纸米白暖调（`#F7F3EA`），替代冷灰底
- 卡片为宣纸白（`#FFFDF8`），搭配暖金描边与顶部鎏金细条
- 背景叠加低透明度金色/檀色径向晕染，模拟水墨氛围

### 1.2 鎏金为骨
- 主操作、选中态、强调元素统一使用鎏金渐变（`#F2DFA0 → #D9B64A → #C9A13B`）
- 金色元素克制使用，作为"描边/细线/渐变小件"出现，避免大面积金底

### 1.3 墨色为文
- 文字采用暖灰墨色层级（`#3A352D → #97917F`），标题用宋体衬线
- 侧边栏采用宣纸米白（`#FDFAF3 → #F8F2E6`），与内容区同属浅色体系

### 1.4 朱砂点睛
- 危险/删除操作使用朱砂红（`#C0392B`），成功用黛绿（`#2E8B57`）
- 功能色仅作状态语义，不做大面积装饰

## 3. 字体规范

### 3.1 字体家族
- **标题/衬线**：`'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', 'STSong', 'SimSun', serif`（`--font-serif`）
- **正文**：`'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', Arial, sans-serif`（`--font-sans`）
- **数字**：`Georgia, 'Times New Roman', serif`（`--font-num`，统计数值、日期序号使用）

### 3.2 字号规范
| 级别 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 页面标题 | 17-24px | 700 衬线 | 页面主标题、卡片标题、弹窗标题 |
| 卡片标题 | 15px | 700 衬线 | 区域标题、仪表盘卡片 |
| 正文 | 13.5-14px | 400/500 | 表格、表单、说明 |
| 辅助 | 12px | 400 | 次要信息、提示 |
| 标签 | 12px | 600 | 徽章、职业标签 |

## 4. 组件规范

### 4.1 按钮
| 类型 | 样式 |
|------|------|
| 主要按钮 | 鎏金渐变底 + 白色文字 + 金色投影；hover 上浮 1px 且触发微光扫过效果 |
| 次要按钮 | 宣纸白底 + 暖金描边 + 墨色文字；hover 金色描边 + 浅金底 |
| 文字/链接 | 鎏金文字，无边框 |
| 危险按钮 | 朱砂红实心/描边 |

**按钮动效**：主按钮 `::after` 斜向白色高光从左向右扫过（0.5s），hover 时 `translateY(-1px)` + 阴影增强。

> **2026-09-28 用户决策（已知接受项，勿再改动）**：主按钮坚持「白色文字 + 浅鎏金渐变」观感，与项目「浅色雅金风·整体调浅」方向一致。白字对浅金底对比度约 1.18–1.57:1，不达 WCAG AA（4.5:1），此为**有意的美观取舍**，作为已知接受项保留。**后续代码审查不得再将主按钮文字改为深色/墨色。**

### 4.2 卡片
- 宣纸白底 + `--edge-soft` 边框 + 12px 圆角
- **顶部 2px 鎏金渐变细线**（`--gold-line` 中部深金、两端透明）
- 阴影：暖色投影 `0 1px 2px rgba(88,66,20,0.06)`（--shadow-sm）
- hover：`--shadow-md` + 上浮 3px（仅交互卡片）

### 4.3 弹窗（Dialog）
- 宣纸白底 + 12px 圆角 + `--shadow-lg`
- 标题宋体 17px + **标题下方 56px 宽鎏金渐变短横线**
- 底部按钮区以 1px 淡分割线上抬

### 4.4 表格
- 表头：`#F7F2E7 → #F1EADD` 渐变底、墨色加粗文字
- 行 hover：`--gold-50`；选中行：`--gold-100`
- 单元格 10px 上下内边距，边框 `--edge-faint`

### 4.5 标签/徽章
- 胶囊形（20px 圆角）、无边框
- 职业标签：职业色实底 + 白/黑对比文字（详见 §7）

### 4.6 输入框/选择器
- 8px 圆角 + 暖金描边
- 聚焦态：金色描边 + `rgba(201,161,59,0.15)` 3px 光晕

### 4.7 标签页（Tabs）
- 激活项：鎏金渐变 3px 下划线 + 金色文字；未激活墨色 500

### 4.8 进度条
- 轨道 `--edge-faint`；完成色默认鎏金渐变，100% 时转黛绿（录屏审核进度）

### 4.9 分页
- 页码圆形/8px 圆角浅金描边；激活页鎏金渐变底白字

## 5. 布局规范

### 5.1 页面结构
```
┌─────────────────────────────────────────────────┐
│  宣纸米白侧边栏（208px，右侧鎏金细线描边）        │
│  Logo：金印「令」+ 鎏金渐变衬线标题               │
│  菜单：44px 圆角项，激活=浅金底+金色文字+左金条    │
├─────────────────────────────────────────────────┤
│  顶部栏（62px 半透明宣纸白 + 毛玻璃）             │
│  左侧：金条装饰 + 宋体页面标题                    │
│  右侧：金色圆形头像 + 用户名 + 角色胶囊            │
├─────────────────────────────────────────────────┤
│  主内容区（24px 内边距，最大宽 1440px 居中）       │
└─────────────────────────────────────────────────┘
```

### 5.2 登录页
- 宣纸渐变底 + 3 个水墨晕染光斑（CSS 径向渐变 + 14s 缓浮动效）
- 中央卡片：宣纸白 94% 透明度 + 毛玻璃 + 顶部鎏金线 + 0.5s 卡片入场动画
- 品牌区：52px 鎏金渐变「令」印章 + 宋体标题 + 金色按钮

### 5.3 统计卡片（仪表盘）
- 4 列网格；数值 30px 衬线 + **鎏金渐变文字**
- 卡片底部 3px 鎏金渐变横条；入场依次延迟 60ms 上浮

### 5.4 排表编辑器
- 候选池：宣纸米白面板 + 成员卡片带职业色圆点
- 队伍分区：**进攻类**暖金描边、**防守类**靛青描边，队号圆形金徽章
- 槽位：虚线暖金描边，hover 变实线；已填充槽位 = 浅金渐变 + 左侧 3px 金条

## 10. UI 优化补充规范

> 详见独立文档：`ui-polish-plan.md`（UI 优化完整方案，含 11 项优化清单、验收标准、文件变更清单）

### 10.1 动画族规范

| 动画名 | 应用场景 | 视觉效果 |
|--------|---------|---------|
| `stat-pop` | 统计卡入场 | scale(0.95) + fade → scale(1) |
| `card-slide` | 列表卡入场 | translateY(16px) + fade → translateY(0) |
| `medal-shimmer` | 排行榜奖牌 | 金色/银色高光从左到右循环扫过 |
| `slot-bounce` | 排表槽位放入 | scale(1.05) → scale(1)，金色边框闪烁 |
| `save-flash` | 保存成功 | 金色光晕扩散 |
| `prof-tag-sweep` | 职业色标签 hover | 白色高光从左上到右下扫过（0.5s，仅 hover:hover 设备） |

### 10.2 卡片层级规范

| 层级 | 应用场景 | 底色 | 阴影 |
|------|---------|------|------|
| 主内容卡 | 表格/列表/编辑器 | `--ink-bg-paper` | `--shadow-sm` |
| 统计卡 | 数值展示 | 金色渐变底 | `--shadow-sm` |
| 辅助卡 | 快捷操作/职业分布 | `--ink-bg-cream` | 无或极淡 |
| 信息条 | 历史总览 | `--ink-bg-wash` | `--shadow-sm` |

### 10.3 交互反馈增强规范

| 元素 | 交互 | 效果 |
|------|------|------|
| 主按钮 | hover | 微光扫光 60% 宽，透明度 0.55 |
| 弹窗标题 | 渲染 | 金线与标题等宽，两端渐隐 |
| 侧边栏菜单 | hover | background 渐变过渡 |
| 滚动条 | 全局 | thumb #d4c5a0，track #f5f0e6 |
| 职业色标签 | hover | 微光扫过（与主按钮扫光同族，峰值 0.42 更克制；触屏与 reduced-motion 停用） |
| 表格密度 | 顶栏开关 | 标准 13.5px/10px ↔ 紧凑 12.5px/6px（localStorage 持久化，移动端隐藏） |

### 10.4 空状态插画规范

- 统一组件：`components/common/EmptyState.vue`（内核 el-empty + 自定义插画，默认 slot 承接操作按钮）
- 插画风格：手绘线条 SVG——金线（`--gold-400`/`--gold-500`）描边 + 宣纸白（`--ink-bg-paper`）填充 + 墨色淡线（`--ink-300`），尺寸对齐原 el-empty image-size（60/72/80，默认 88）
- 变体映射：`empty` 无数据（空白册页）· `search` 无结果（放大镜）· `chart` 图表无数据（折线坐标）· `error` 加载失败（朱砂警示圆）
