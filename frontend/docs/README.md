# 前端项目 开发文档

## 需求说明

### 功能概述
基于 Vue 3 + TypeScript + Vite + Element Plus 的前端应用，提供管理员与帮众两套视图，覆盖常驻库、联赛日程、出勤库、排表拖拽、录屏审核、数据分析、系统配置等页面，采用 v2 设计文档的浅金色风格（#D4AF37）。

### 业务目标
- 按 ui-style-guide.md 落地浅金色主题、组件、布局规范
- JWT 认证链路：登录页 → Pinia 状态 → 路由守卫 → Axios Token 注入
- 角色区分：管理员完整菜单，帮众仅可见出勤/排表总览/录屏提交/数据分析

### 用户场景
- 管理员：登录后管理成员、创建赛程、维护出勤、拖拽排表、审核录屏、导入 CSV 分析、系统配置
- 帮众：查看出勤表与排表总览，找到自己的行切换请假状态、提交录屏链接
